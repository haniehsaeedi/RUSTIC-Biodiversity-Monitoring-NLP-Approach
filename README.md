# RUSTIC-Biodiversity-Monitoring-NLP-Approach
This repository includes all the Python scripts used for the NLP approach used to review the RUSTIC-relevant resources extracted from OpenAlex.
knowledge required is compiled following the best standards. Section 2.3 (Guiding Principles of Monitoring Workflows) of Chapter 2 highlights and defines several important best data practice principles beyond 
the FAIR and CARE principles suggested as RUSTIC to:
1. Enhance and facilitate monitoring programs at any scale, and 
2. Promote advancement towards the creation of a global network of monitoring programs 
3. Meet the needs of the Global Biodiversity Framework
The goal of this DMR is to establish the protocol used to identify quality criteria of the data needed to support the global monitoring framework. A combination of the RUSTIC- and biodiversity monitoring relevant
keywords was used to search the literature and extract appropriate references for the review approach via the OpenAlex API using the PyAlex Python library.
The aim was to systematically gather scientific resources with specific search queries related to biodiversity monitoring.
